**Laravel A-Ray** (`subvitamine/laravel-a-ray`) is a Laravel package that connects your application to the [A-Ray](https://a-ray.io) monitoring platform. Use it to send structured debug traces (called *pushes*) with labelled commits, monitor your API endpoints in real time, mask sensitive request fields, and receive Slack notifications when errors occur — all from within your existing Laravel application.

## Get Started in Minutes

<Steps>
  <Step title="Install the package">
    Require the package in your Laravel project using Composer:

    ```bash
    composer require subvitamine/laravel-a-ray
    ```
  </Step>
  <Step title="Configure your environment">
    Add your A-Ray credentials and preferences to your `.env` file:

    ```dotenv
    A_RAY_ENABLED=true
    A_RAY_PRIVATE_KEY=pk_XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
    A_RAY_NOTIFY_ERRORS_ENABLED=false
    A_RAY_NOTIFY_CHANNEL=slack
    ```

    You can find your private key in your A-Ray project settings.
  </Step>
  <Step title="Initialise a push">
    In your application code, import the `ARay` and `CommitStatus` classes, then create a new push and attach one or more commits:

    ```php
    use Subvitamine\LaravelARay\ARay;
    use Subvitamine\LaravelARay\CommitStatus;

    $push = ARay::initPush('User login');

    $push->addCommit(
        'User login attempted',
        ['user_id' => $user->id, 'ip' => $request->ip()],
        CommitStatus::INFO
    );
    ```

    Each commit has a label, an optional data payload, and a status level: `SUCCESS`, `INFO`, `WARNING`, or `ERROR`.
  </Step>
  <Step title="Send the push to A-Ray">
    Dispatch the push to the A-Ray platform with a single call:

    ```php
    ARay::push($push);
    ```

    Your push will appear in your A-Ray dashboard immediately.
  </Step>
</Steps>
